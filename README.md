# いまなにしてる？ — ステータス通知アプリ

相手が今なにをしているか分かるアプリです。
名前を入れてボタンを押すと、もう片方の画面に「○○さんが【勉強中】になりました」と
リアルタイムで通知が飛びます（画面表示＋ブラウザのポップアップ通知）。

## つかいかた

```bash
node server.js
```

起動したら、ブラウザで http://localhost:3000 を開きます。

- 自分と相手が、それぞれこのURLを開きます
- 名前を入れて、状態ボタン（勉強中・ご飯中・寝てる…）を押します
- もう片方の画面に通知が届きます
- 「🔔 ブラウザ通知を許可する」を押しておくと、画面を見ていなくてもポップアップで届きます
- 下の **履歴** に、全員の“今の状態”がカードで一覧表示されます
  （同じ人は1枚のカードに上書きされ、「○分前に更新」も表示されます）

> 自由入力欄に文字を書いて「送信」を押すと、好きなひとことも送れます。

## 自分用スマホダッシュボード（`/dashboard`）

自分専用のホーム画面です。`http://localhost:3000/dashboard`（公開後は
`https://〇〇.onrender.com/dashboard`）を開くと使えます。スマホでひらいて
「ホーム画面に追加」しておくと、アプリのように一発で開けて便利です。

のっているもの：

- **時計・日付**：大きく見やすく、あいさつも時間帯で変わります
- **天気**：位置情報から今日の天気・最高/最低気温・降水確率を表示
  （Open-Meteo を利用。APIキー不要。位置情報を許可しないと東京の天気になります）
- **マーケット**：日経平均・NYダウ・S&P500・ドル円を前日比つきで表示
  （Yahoo Finance を利用。5分ごとに自動更新。「更新」ボタンでも更新できます）
- **やること（ToDo）**：追加・チェック・削除ができます
- **メモ**：書くと自動で保存されます
- **ショートカット**：よく使うサイトへのリンクを自由に追加・削除できます

> ToDo・メモ・リンク・天気の場所などのデータは、**開いているこの端末**
> （ブラウザ）の中だけに保存されます。サーバーには送られません。

## 仕組み（かんたん解説）

- `server.js` … Node.js の標準機能だけで動く小さなサーバー。追加インストールは不要です。
  - 状態の受け取り（`POST /status`）と、リアルタイム配信（`/events`、Server-Sent Events）をします。
- `public/index.html` / `public/app.js` … 画面側。ボタンや通知の表示を担当します。
- `public/dashboard.html` / `public/dashboard.js` … 自分用ダッシュボードの画面。
  サーバーは天気・マーケットの代理取得（`/market`）だけ担当し、データ保存はしません。

## インターネットに公開する（Renderで無料サーバーを作る）

離れた場所の相手とも使えるように、無料の Render にサーバーを置けます。
クレジットカードは不要です。この手順でURL（例：`https://ima-nani-shiteru.onrender.com`）が
発行され、自分も相手もそのURLを開くだけで使えるようになります。

1. **GitHubに上がっていることを確認**
   このアプリはすでに GitHub にあります。Renderはそこから読み込みます。

2. **Renderに登録**
   https://render.com を開き、「Get Started」→ GitHubアカウントでサインアップ。

3. **Blueprintで読み込む**
   ダッシュボードで **New ＋ → Blueprint** を選び、このリポジトリ
   （`my-first-app`）を選択。同梱の `render.yaml` を自動で読み込みます。
   → **Apply** を押すとサーバーが作られます（数分待ちます）。

   ※「Blueprint」が見つからない場合は **New ＋ → Web Service** を選び、
   リポジトリを指定。設定はこれだけ入力すればOKです：
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - Instance Type: `Free`

4. **完成したURLを開く**
   `https://〇〇.onrender.com` というURLが表示されます。
   自分と相手でそのURLを開いて、名前を入れてボタンを押せば通知が飛びます。

> **無料プランの注意**：しばらく誰もアクセスしないとサーバーが一旦“お休み”します。
> 次に開いたとき、最初の表示だけ30秒ほど待つことがあります（その後は普通に動きます）。

## （おまけ）同じWi-Fi内だけで使う

デプロイせずに試すなら、サーバーを動かしているパソコンのIPアドレス
（例：`http://192.168.1.10:3000`）を、同じWi-Fiにいる相手に開いてもらってもOKです。
